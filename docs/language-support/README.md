# Language support

Supported: English, Hindi, Odia, Bengali, Telugu, Tamil, Kannada, Malayalam, Marathi, Gujarati, Punjabi, Assamese, Urdu, Hinglish/mixed.

`LanguageDetector` uses script ranges + keyword heuristics. Mixed Latin + Devanagari often classifies as `hinglish`.

Templates live in `libs/localized-response-templates` and always append a risk disclaimer.
